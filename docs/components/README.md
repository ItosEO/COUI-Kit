# 组件目录

需要在布局中直接使用控件时，从这里选择。首次接入见[快速开始](../guide/getting-started.md)。

| 组件 | 用途 |
| --- | --- |
| [顶栏与按钮](top-app-bar.md) | 渐进模糊背景、页面标题和操作 |
| [顶栏搜索](search.md) | 搜索按钮与输入框之间的转场 |
| [底栏](bottom-bar.md) | 页面选择、左右附件和融合表面 |
| [FAB](fab.md) | 独立浮动操作 |
| [菜单](menu.md) | 选择、勾选、分组与子菜单 |
| [滑动选择条](slider.md) | 连续、分段与隐藏点位的步进选择 |
| [复选框](checkbox.md) | 勾选状态与切换动画 |
| [ChipTab](chip-tab.md) | 单选分类、横向滚动与独立图标动作 |
| [弹窗](dialog.md) | 底部/居中窗口、受控操作与输入型预设 |

各页说明状态、回调及平台要求。浮动材质需要的公共准备见[背景采样](../effects/backdrop.md)；单独使用算法见[效果目录](../effects/README.md)。

维护这些页面时遵循[component 文档写法](../development/documentation.md#component-页面)。
