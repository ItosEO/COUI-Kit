# 代码规范

## Kotlin 与 Compose

- 文件使用 UTF-8，无 BOM。标识符、格式和声明顺序沿用所在组件族；库 KDoc、解释性注释、开发文档及提交说明使用简体中文。
- 默认声明为 internal 或 private，仅为真实外部用法公开 API。组件的 Modifier 为第一个参数，默认值为 Modifier。
- 无状态预设使用 object，归属对应组件族的 Defaults。组件可使用原生 CouiTheme 默认值，宿主可显式覆盖 Shape、Style 和颜色；业务回调从宿主传入，核心不读取应用偏好或 MaterialTheme。可选 coui-material3 仅按[外观契约](../guide/appearance.md)在消费处读取 MaterialTheme。
- 值、选择和展开目标采用受控状态与回调。宿主拥有业务状态，组件维护局部交互，避免并行维护同一事实。
- 列表身份使用稳定且唯一的 key。绘制范围与命中范围分别确认，渐隐和裁剪不能代替输入限制。
- 整行承担交互时，子控件不重复添加点击；保留禁用、键盘、焦点、TalkBack 和正确的选择语义。
- 输入观察器不能抢占点击或滚动，普通触摸提交只有一个 owner。事件命名说明动作或结果；CANCEL 不提交业务动作。停止动画、父容器接管和节点移除均有对应收尾。
- 不为复用增加只转发参数的层。

## 资源、错误和绘制

- 背景、效果和业务状态分开。每个绘制节点独立持有可变 renderer。动画、监听和图层随对应节点释放，不建立全局历史缓存。
- 不吞错误、不模拟成功、不新增静默降级。已有平台兼容路径保留明确语义；Shader 创建失败交给宿主记录并决定替代 UI。协程捕获 `CancellationException` 后重抛。
- 不新增 `!!`。
- 用户文案进入所属模块的字符串资源，默认英文并同步已有简体中文。库不依赖应用日志框架；需要诊断时用明确回调，避免逐帧日志。
- 不为单个组件升级无关依赖、引入另一套主题或样式框架。

像素算法和预设参数在代码集中维护。绘制使用明确的本地、窗口和屏幕坐标；公开接口的单位及生命周期见[API 设计](api-design.md)。

## 注释与示例

注释说明依据、约束、非直观意图和接口契约，不复述代码或记录修改历史。原厂符号可用于定位来源；原厂证据与当前适配分开说明。

Demo 只调用公开 API。示例修改同时遵守[文档维护规则](documentation.md)，保持名称、受控值、回调条件和平台门槛一致。
