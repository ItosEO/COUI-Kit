# Agent Note: 分类栏选中项的滚动联动

Status: implemented

## Problem

外部选择入口更新分类栏的受控选中值后，选中项可能仍在可视区域外。点击半露出的项目时，将渐隐宽度额外计入滚动终点会扩大图标标签与该项目之间的留白。长项目的文字还需按可见宽度省略。

## Decision

[ChipTabRow](../../../../coui/src/main/java/com/itos/coui/chip/ChipTabRow.kt) 在测量完成后比较前后选中 key、索引和布局。选中值、项目位置或可用范围变化时，先停止惯性和旧露出动画，再复用 `reveal` 与已有弹簧滚动到对应项目。等宽项目重排可能保持所有几何数组不变，因此必须同时比较选中索引。点击与键盘焦点使用同一条滚动路径。

滚动终点使用当前内容可见区和已有列表内边距。原厂 `COUIChipTabGroup.updateContentVisibleRect` 调整可见区后，`scrollToChipTabWithAnimation` 直接以项目边界和可见区边界之差作为位移，没有额外加入渐隐宽度。移植的 `reveal` 保留这一终点语义；Compose 遮罩在停靠边界外完成过渡，使该边界内的胶囊保持完整。渐隐不再作为额外滚动留白，绘制裁剪与渐变使用同一段范围。项目最大宽度受可视范围约束，长文字沿用省略显示。按下时冻结滚动及新目标的启动速度由[滚动中断决定](2026-10-24-chip-scroll-interruption.md)持有。

首次布局不触发该联动，保留初始位置或保存的滚动位置。普通重组、手动滚动和页面恢复不因选中值及布局未变而回滚。滚动只调整可见范围，不改变键盘焦点或再次通知选中回调。

本篇部分更新[分类栏装配决定](../feature/2026-10-24-chip-tab.md)中的外部选择行为，保留其受控状态、材质和滚动算法。

## Alternatives considered

- **仅由 Demo 在弹窗关闭后滚动。** 修改局部，但其他受控调用方仍会遇到选中项不可见的问题，并需要额外暴露滚动状态。
- **每次布局都露出选中项。** 容易实现，但会覆盖手动滚动和保存的位置，因此仅在已完成首次布局且选中 key 或项目可用范围变化时触发。
- **选中项靠近边缘时关闭渐隐。** 可避免遮挡，但会失去后续内容的滚动提示；保留原厂渐隐与滚动终点。

## Consequences

弹窗与其他外部选择入口共享分类栏的滚动联动，无须新增公开接口或动画实现。布局先更新项目位置，再计算露出目标，兼容不同项目宽度和 RTL 放置。关闭前置按钮、改变标签或调整窗口宽度时，也会检查选中项。代价是窄容器内的长文字会更早省略。实际点击、动画与绘制仍需运行验证。
