# Agent Note: 底栏和独立 FAB 拖拽与父级滚动的输入所有权

Status: implemented

## Problem

底栏和独立 FAB 的形变只观察触摸，放在可滚动页面中时，父级仍能接管同一移动，导致拖动按钮时整页也滚动。没有业务操作的展示节点还被强制要求提供点击回调，移除业务动作后只能留下空回调或隐藏节点。

## Decision

NavigationBar 的附件与独立 Fab 允许省略点击回调。图标、描述、可见性与融合收尾继续由各组件原契约控制；没有回调时不添加 clickable 或 Button 语义，但保留拖拽、按压和跟手光。已有非空回调仍由组件唯一的点击入口提交。

底栏的 FloatingNode 与独立 Fab 通过内部 consumeDrag 路径参与触摸所有权。位移超过系统触摸阈值后，在 Initial 阶段消费移动，防止父级滚动接管，并取消子项可能残留的点击。阈值之前不消费，轻触保持原有行为。多指交接调整拖拽原点，保留累计位移；UP、CANCEL 和节点移除继续释放原有运动与速度跟踪器。

公开 couiTouchMotion 仍是观察器，菜单、搜索与顶栏按钮不接管手势。弹窗已有的父滚动取消路径继续使用自己的 cancelOnConsumedMove。不通过禁用整页滚动或拦截整个预览区域处理问题，空白区域仍可滚动页面。

Demo 的底栏附件只展示显隐和拖拽，不接入导航或计数。中间导航项仍更新本页的选中状态。

## Alternatives considered

- **给预览附件传空点击回调。** 可以少改库代码，但仍生成可以点击的无效按钮语义，无法表达没有业务动作的展示附件。
- **在预览区域拦截所有手势或暂停整页滚动。** 装配简单，但会改变空白区域、其他控件和父级惯性的行为，输入范围超过实际拖拽节点。
- **让公共 Touch Modifier 默认消费移动。** 能同时改变所有消费者，但会破坏搜索输入、滚动内容和弹窗已有的输入协作，因此只由底栏显式启用。

## Consequences

底栏与独立 FAB 可以展示没有业务点击的节点，拖拽有明确的移动所有者。底栏公共签名不变，显示附件仍必须提供图标和描述；独立 Fab 的 onClick 允许为空并可省略。用法见[左右附件](../../../../docs/components/navigation-bar.md#左右附件)和[FAB](../../../../docs/components/fab.md)。

阈值、交接和消费分支的离线检查不能代替 Compose 的实际事件分发。父滚动、轻触、出界、CANCEL、多指、隐藏收尾及拖动后不误点击仍需设备验证，未执行 Android 构建或设备操作。
