# Agent Note: Demo 聚焦组件与常用效果

Status: implemented

## Problem

全量效果展示让 Demo 页面过长。用户要求保留常用组件与效果，移除独立光效、形状、动画和状态反馈分组，同时统一滑条样式并减少重复文案。

## Decision

保留组件、效果和预设三页。效果页只展示胶囊阴影、双主体融合、背景采样与模糊、材质混色；删除表面轮廓/内晕、背景感知轮廓、跟手光、COUI 形状、动画预设、悬停/焦点反馈的独立分组与专用实现。库内对应算法和组件交互不变，组件自身的光效与形变仍由原实现负责。

阴影固定使用 SmoothCapsule，保留便捷与低层接口切换。两种入口按主体短边的一半使用同一半径，不再保留形状选择状态。全部数值滑条直接使用公开 Slider，保留原范围、受控值和步进；不用额外包装层或 Material Slider。

移除顶部 FAB/附件点击计数及状态。独立 FAB 与右侧附件打开现有预设页，顶栏重置恢复默认配色，使保留的点击入口仍有可见作用。删除预设页重复的深浅色按钮和顶部说明；顶栏及左附件继续切换主题。清理专用双语资源、搜索标题和已无用途的 Demo Shape。

README 持有当前展示范围，AGENTS 与 Developer 同步为按已选范围维护示例，不再要求所有公开效果均建立独立面板。主题、语义、背景源和状态 owner 继续沿用既有装配。

## Alternatives considered

- **仅隐藏分组，保留全部专用代码和文案。** 修改少，便于恢复，但会留下没有入口的实现和搜索资源；按用户确定的范围删除专用内容，库接口仍可复用。
- **只改滑条示例，保留调参区的 Material Slider。** 可以少传主题与形状参数，但不满足所有滑条统一 COUI 样式的要求；直接调用现有公开组件。

## Consequences

[记录侧滑示例](2026-10-24-demo-record-swipe.md) 进一步收窄融合展示为三条记录，移除手动调参与说明，并统一自适应滑条、菜单分组及复选框无涟漪反馈；本篇的页面和展示边界继续有效。

Demo 更短，数值输入一致；独立图形能力的展示覆盖减少。后续需要单独观察已移除效果时，先根据任务确定展示范围，不自动恢复全量图库。

本轮只修改 Demo 与相关文档，不修改公共 COUI 实现或构建依赖。验证覆盖 Kotlin 语法、公开接口调用参数、搜索分组、双语资源引用及文档链接。Android 构建、Preview、安装和设备视觉/触摸验证由用户执行。

初次精简的静态检查通过：76 个 Kotlin/KTS 文件的 PSI 语法、52 个 COUI 公开导入及 98 处可定位的 COUI/Demo 调用参数；67 组双语资源、八个搜索分组、八处 COUI 滑条及文档链接一致。另检查了胶囊两种投影入口、预设跳转和重置接线、已删功能残留、Note 格式和差异。检查不执行 Android 类型编译或真实绘制；临时检查器不加入仓库。
