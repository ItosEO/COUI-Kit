# Agent Note: Demo 的 M3 装配与 COUI 展示

Status: implemented

私有 M3 配置开关、同页标题筛选和分组保存层由[目录式 Demo](2026-11-01-demo-catalog-and-system-icons.md)部分取代。下文保留原 gallery 选择的理由；M3 语义、业务 owner 和背景分层继续有效。

## Problem

Demo 将设置开关都画成复选框，预设选择缺少单选语义，M3 导航通过禁用按钮表示当前页。展示虽已包含主要组件，但独立效果、公开预设和若干组件状态缺少可观察入口。

后续新增的库内 COUI 开关与状态示例见[开关组件](2026-10-27-coui-switch.md)。本篇关于 App 私有开关的决定继续限定于 M3 配置项，新组件示例不全局替换这些项。

## Decision

Demo 独立维护主题、形状、开关、复选框、顶栏搜索和导航，并按 M3 规范核对组件语义和无障碍。系统动态色作为 Demo 的主题输入，页面与卡片使用不同的表面层级。G2 形状、开关与 Capsule 依赖只放在 App，不引入公共 COUI 模块。

设置项使用 G2 开关，整行持有 Switch 语义与 InteractionSource；预设使用单选组；复选框示例保留独立的 Checkbox 语义和禁用态。M3 导航使用标准 NavigationBar / NavigationRail 的选中态，横屏切为侧栏。搜索使用受控 InputField 接口，处理焦点、键盘与返回；COUI 搜索同时演示退场与常驻操作。页面和分组分别保存示例状态，切页或筛选不重置已调整的受控值。

COUI 展示覆盖所有现有 UI 组件族及可独立观察的视觉效果：菜单增加图标、分隔、禁用项和长列表，滑条覆盖可见分段及隐式步进；阴影可选择全部轮廓并切换便捷与低层接口；补齐背景采样、模糊、材质混色、表面轮廓、背景感知轮廓、全部跟手光预设、形状、按压形变及三类状态反馈。底栏左右附件独立控制，顶栏按钮可禁用，原有 FAB 配色、融合与内容遮罩继续可交互展示。

局部背景示例使用各自的采样源，源内只有不透明背景图案，效果面板作为兄弟节点；顶栏、底栏和 FAB 保留在页面源之外。公共库接口与算法不因演示需要改变。

## Alternatives considered

- **让全部设置继续使用 COUI 复选框。** 改动少，但开关与单选意图不清，也不能验证对应的 M3 交互。
- **直接依赖外部宿主的 Design System。** 可以复用项目组件，但独立 Demo 会重新依赖原工程及其配置、主题和业务资源。
- **只列出效果名称或增加不可操作的占位卡片。** 不能观察真实输入、绘制和状态，因此直接调用公开能力生成交互示例。

## Consequences

[分类栏](2026-10-24-chip-tab.md) 加入组件页和标题搜索。Demo 持有名称、图标、选择状态及独立动作。

当前展示范围由 [Demo 精简](2026-10-24-demo-focused-showcase.md) 部分取代：取消全量独立效果分组和阴影形状选择，统一数值滑条并精简计数与文案；本篇的 M3 语义、状态 owner 和背景分层决定保留。

后续 [公开 API 收口](../architecture/2026-10-23-public-api-boundary.md) 保留本篇的消费者和展示定位，[开发流程](../process/2026-10-23-developer-guide-and-pr-notes.md) 约束新增示例与依据记录；不撤销本次 M3 装配决定。

App 展示源码按主题、公共控件、主要组件、视觉效果、阴影和运动分开，入口及展示范围由根 README 维护。平台条件沿用各公开 API；不为旧平台伪造 GPU 光效。低层调试探针与内部 Shader 辅助逻辑通过所属组件观察，不视作独立 UI 组件。

静态检查覆盖 Kotlin/KTS 语法、COUI 公开导入及参数、Demo 内部调用、所有分组的搜索入口、双语资源及格式参数、M3 状态语义、文档引用和模块边界。Material3 接口按版本目录对应的本地源码核对。未执行 Android 构建、Gradle Sync 或设备验证；大字体、TalkBack、真实焦点、触摸、GPU 绘制及视觉结果仍由用户验证。
