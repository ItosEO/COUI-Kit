# Agent Note: ChipTab 的状态与装配

Status: implemented

## Problem

横向分类栏需要单选分类、独立动作、背景材质及边缘遮罩。分类项与顶栏按钮共享部分效果，但尺寸、选择规则和滚动行为不同，需要独立装配。

## Decision

通用分类组件、材质预设和滚动算法归 `com.itos.coui.chip`；名称、图标、选择状态及动作归宿主。公开入口为 [CouiChipTab / CouiChipTabButton](../../../../coui/src/main/java/com/itos/coui/chip/CouiChipTab.kt) 和 [CouiChipTabRow](../../../../coui/src/main/java/com/itos/coui/chip/CouiChipTabRow.kt)，Demo 通过公开 API 装配。

`CouiChipTabRow` 使用受控 key，非空列表必须选择现有项目。重复点击保持选择并检查项目遮挡；仅在选中项变化时通知宿主。`CouiChipTabButton` 是单选组外的独立动作，`leadingAction` 为 null 时只显示横向列表。选中项的完整露出行为由[选中项可见性决定](../bug-fix/2026-10-24-chip-selection-visibility.md)持有。

动作显隐复用 `CouiTopAppBarActionVisibility` 的横向收放与淡化，列表留白使用相同的时长和曲线过渡。宿主需要退出过渡时，保留 `leadingAction` 内容，只切换 `leadingActionVisible`。隐藏过渡完成后，动作内容退出组合，不保留布局空位。

## 绘制与输入

分类项复用单主体浮动后端，每个节点独立持有 renderer，创建失败由宿主处理。材质使用两层混色和背景模糊，颜色通过 Android `ArgbEvaluator` 插值。选中弹簧驱动材质、轮廓与阴影变化，不整体淡出节点。内晕复用 `floatingInnerGlow` 并保留零终点 alpha，避免选中项内部过白。

阴影复用 `CouiTopAppBarButtonDefaults.shadow` 的胶囊按钮预设，再按选中进度调整 elevation 和外光晕 alpha。这样能沿用现有按钮的投影强度与光学布局，避免浅色背景上的底部亮带。

点触光通过 `beforeContent` 在材质之后、内容之前混合，直接使用后端缓存的裁剪路径。不能先混入透明内容层，否则会改变混合结果。回调负责变换和裁剪，不修改缓存路径；预设重建点触光状态时，输入协程同步绑定新实例。

按压复用 `couiPressMotion`，直接观察输入，避免 `PressInteraction` 延迟。点击、按压和点触光输入位于未缩放的外层，材质与内容单独缩放，防止边缘触点因节点缩小而被取消。分类项和独立图标标签显式开启 `cancelOnConsumedMove`，在 Final 阶段发现父容器已消费移动时立即释放按压，后续移动或加指不重新按压，直到本次触摸结束。点触光同时结束会话；不叠加普通 hover、focus 或 press 蒙层。

该取消规则对应便签与录音 `COUIChip.handleActionCancel` 立即调用 `executeFeedbackAnimator(false)` 的路径。公共按压入口的新增参数默认关闭，FAB、顶栏按钮和搜索的现有拖拽反馈不变。原始 APK 标识及滚动收尾依据见[滚动中断决定](../bug-fix/2026-10-24-chip-scroll-interruption.md)。

## 滚动与遮罩

`CouiChipScrollPhysics` 负责水平惯性与越界回弹：先以 RK4 预测，再按速度缩放距离和时长，以过阻尼插值推进。数值转换、整数截断、积分权重及终止条件影响终点和回弹，保留在同一实现中。名义步长取自公开 Display 接口，实际回弹按 Choreographer 帧间隔推进。

水平链不包含无效的连续 fling 增速和未调用的触边限速。低动画等级的首个实例先捕获初始摩擦，再更新后续实例的默认值，保留该构造顺序。动画等级由宿主显式传入，间距由页面装配，不读取私有系统属性。

点击与键盘焦点共用完整露出路径。选中露出弹簧与拖动、惯性分别管理；按下时的中断和重新启动规则见[滚动中断决定](../bug-fix/2026-10-24-chip-scroll-interruption.md)。

选中值或项目可用范围改变后，在当前布局中露出对应项目；首次布局保留初始或恢复的位置。

边缘遮罩使用 DST_OUT 和物理 scrollX，RTL 改变项目放置及初始位置。列表裁剪同时约束绘制和命中，避免隐藏分类项接收图标按钮区域的点击；纵向保留阴影扩展。滚动帧和弹簧随节点释放；Demo 通过 SaveableStateHolder 保存切页和筛选前的状态。

## 实现依据
独立图标标签是 `COUIChipTab` 的仅图标实例；来源代码字段为 `iconOnlyChip`，由 `setIconOnlyChipVisible` 控制可见性。Demo 使用通用分类文案和现有 Material 图标，默认只显示选项列表。“显示图标标签”开关控制独立标签的可见性。其 renderer 在首次显示时创建，并保留至当前示例实例释放，使退出和快速反向过渡能继续绘制。隐藏期间禁用标签动作，过渡结束后不再绘制标签。点击图标标签通过现有锚点入口打开 COUI Menu，菜单包含全部分类并标记当前选中项；选择后更新分类并关闭菜单。启用状态对整栏生效。

Demo 的“纯色背景”默认开启，展示区域使用浅色纯白、深色纯黑；关闭后沿用所属卡片的底色，不保留黑白底。材质始终采样同色的不透明兄弟节点，避免采样自身或将透明源送入混色。背景随组件尺寸布局，不包含设置开关。该开关只属于 Demo，不改变库的材质和接口。

## Alternatives considered

- **直接复用整个顶栏按钮。** 能共享成熟实现，但尺寸、点触光和选中规则不同；分类项保留独立装配，复用按压、阴影预设和材质后端。
- **使用 Material FilterChip 和默认横向滚动。** 接入简短，但材质混合、惯性和阴影裁剪不同，不能替代分类栏的绘制与滚动链。
- **开关关闭时直接清空动作槽位。** 能立即释放内容，但退出过渡失去绘制对象；保留槽位并切换可见性，让现有动画管理内容退出。

## Consequences

未选中状态的透明 caustic 省略由[绘制工作省略](../simplification/2026-11-01-render-work-elision.md)持有；本篇的选中插值、材质与输入规则保持。

分类栏能独立装配并复用现有效果，宿主只需提供内容、主题和受控状态。代价是仍需维护专用的滚动物理与材质插值。浮动表面保留既有的前景合成和 Path 裁剪限制；非整数像素尺寸下的按压缩放、重叠投影和抗锯齿仍需运行验证。

已有静态检查覆盖语法、公开引用、资源及 Note；JVM 数值检查覆盖四个等级、三种刷新率和正反向等 552 个惯性、回弹场景，检查终止、方向及终点。语法与数值检查不替代 Android 编译和运行验证。

实际绘制、快速反向与取消、多指交接、嵌套滚动、大字体、RTL、键盘焦点和 TalkBack 仍需运行验证。
