# Agent Note: Demo 用记录侧滑展示融合

Status: implemented

## Problem

融合调参面板展示了算法，但距离滑条不能说明它在列表侧滑中的实际表现。用户要求用少量示例记录展示动画，并进一步减少说明文案、长菜单数量和多余点击反馈。

## Decision

融合页以 Metric 的 FpsRecordItem、FpsRecordHistoryContent、RecordSwipeRevealRow 与 RecordMetaballBackground 为列表基准，使用默认圆角设置。三条示例直接放在页面背景上，不包进一张共享分组卡片。应用图标位于滑动主体之外，记录卡片包含标题、筛选标记、时间、FPS、功耗、时长和可选备注。几何、文字和颜色角色由对应 Demo 实现持有；数据及应用图标使用 Demo 本地样例，不接入 Metric 数据库。

DemoRecordSwipeRow 保留手势取消、释放速度、展开回弹、按钮跟随、长拉伸提交、点击确认和离场动画。固定宽度测量内容，避免卡片收缩时文本重新排版。删除开始时淡出外置图标，主体离场结束后收缩整行高度，收缩完成后才移除记录。空闲时按自然高度测量，只在收缩目标生效后冻结高度并乘动画进度；收缩中的尺寸不写回自然高度。否则删除末行时，前一行会保留旧尾间距。长拉删除显示桶盖旋转，点击确认显示勾选图标；两者不合并为同一状态。侧滑与删除状态只属于 Demo。

DemoRecordMetaball 的背景与内容遮罩使用同一几何、各自独立的 renderer，保留离屏 DstIn 与 RTL 坐标转换。同一列表只加载和转换一次应用图标，缓存键包含 Context 和像素尺寸；各行共享这份不变的图像数据，不共享可变 renderer。卡片取 surfaceBright，操作区裁切与融合半径使用同一记录 Shape。颜色继续服从 Demo 的 Material/原生主题开关。COUI 的算法、公开接口与依赖不变，库仍不提供侧滑容器。平台门槛沿用原融合示例，旧系统显示要求；创建失败明确显示错误。

记录使用稳定 key，列表、展开项和预览状态归页面，单次只展开一项，全部删除后提供恢复入口。未展开时点击查看本条样例，关闭预览后显示不参与侧滑的最近查看短弧；已展开时点击收起操作区。样例预览复用当前记录内容，不复制 Metric 的完整详情业务。卡片与操作按钮保留点击语义，另提供展开操作区的无障碍动作，删除动画期间禁用内容点击。

两种采样面板移除前景文字，各数值滑条占满父级可用宽度；复选框行保留 toggleable 语义并关闭 indication。长菜单保留四组三项，通过高度上限触发滚动。普通菜单和子菜单继续可用。

## Alternatives considered

- **继续用滑条驱动融合。** 装配少，容易单独观察算法，但不能满足直接观察记录侧滑的要求；旧画布、开关、说明及专用资源一并移除。
- **把侧滑容器加入 COUI。** 宿主更容易接入，但会把删除确认与列表状态带入算法库；示例在 Demo 适配原宿主链路，只消费公开算法。
- **重新写一个拖动位移示例。** 代码更少，但需要重新处理取消、速度、内容遮罩和 RTL，并可能丢失原宿主已有的动画行为；保留原链路，只去除业务依赖和本示例不用的旧平台绘制分支。

## Consequences

Demo 可以观察真实触摸驱动的融合，示例删除仅影响页面状态。接口使用方法见 DemoRecordSamples、DemoRecordSwipeRow 和 DemoRecordMetaball；这些文件不构成库的公开 API。旧系统不创建 RuntimeShader。

源码对照覆盖 Metric 的默认圆角、卡片排版、手势、固定宽度、背景/遮罩几何与删除生命周期。Demo 的样例数据和预览入口独立维护；Metric 列表变化需要显式对照，不建立跨工程源码或构建依赖。

设备触摸、TalkBack 与 GPU 结果仍需动态验证。语法与源码检查不执行 Android 类型编译，也不能证明原厂效果等价；实际 CI 和其他检查结果由 PR 记录。
