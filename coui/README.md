# COUI 库模块

coui 是独立 Android Library，包名 com.itos.coui，依赖 Android、Compose 和 AndroidX。宿主提供主题、Shape、业务状态与回调。

| --- | --- |

| 接入预览版 | [GitHub Packages](../docs/guide/github-packages.md) |
| 顶栏、搜索、底栏、FAB、菜单、滑条、复选框、开关、ChipTab、弹窗 | [组件目录](../docs/components/README.md) |
| 背景采样、阴影、模糊、材质、光效、运动与融合 | [效果目录](../docs/effects/README.md) |
| 修改模块或公开接口 | [架构](../docs/development/architecture.md)、[API 设计](../docs/development/api-design.md) |
